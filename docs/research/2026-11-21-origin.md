# Origin and early research (2026-11-20 / 21)

How the project started and what was learnt before writing any code. Kept as context for future decisions.

## Starting point

Interest in Guesstimate (getguesstimate.com, MIT, by Ozzie Gooen / QURI): a spreadsheet where cells hold ranges (`25 to 35`, a 90 % interval, normal by default), point values or empirical data; formulas reference other cells by two-letter IDs; a Monte Carlo engine draws 5,000 samples per input and shows percentiles, mean, median and a histogram per cell. It also turns models into simple "calculators" for others to fill in. Architecture: Next.js/React front end with math.js for expression evaluation, a Rails + PostgreSQL backend storing each model ("space") as JSON, Auth0 and Algolia. For personal local use almost none of the backend is needed.

Options considered for a personal tool:

1. Run guesstimate-app locally: high effort (Auth0, Rails backend) for no gain.
2. Use Squiggle, QURI's successor language: zero effort, text-based, but no visual canvas.
3. A small single-file HTML app (math.js + charts).

Squiggle was tried first; the conclusion was to build a `bc`-like Go CLI instead.

## Squiggle experiment

- Installed `@quri/squiggle-lang` 0.10.0 with npm (Node 26).
- The CLI (`dist/cli/index.js run FILE`) failed with missing modules: had to install `date-fns`, `ink@5`, `react@18`, `commander@12` and `open` manually (latest `@commander-js/extra-typings` conflicts with `commander` 15).
- Identifiers must be ASCII: `costeAño` is a parse error ("Expected ... but "ñ" found").
- `squiggle playground` only opens the hosted web playground.
- Output prints distributions as `Sample Set Distribution`; summaries need explicit `quantile()` / `cdf()` calls and print with full float noise (`96.98057045115692`).
- Upstream status on 2026-11-21: `quantified-uncertainty/squiggle` MIT, last push 2026-11-04, not archived; `getguesstimate/guesstimate-app` MIT, last push 2026-11-17, 2.4k stars.

The model used ([homelab.squiggle](homelab.squiggle)) compares the yearly cost of a home server against a VPS. With the guessed inputs, yearly saving was p5 ≈ 22 €, p50 ≈ 97 €, p95 ≈ 237 €, and P(homelab more expensive) ≈ 0.9 %. The inputs are illustrative guesses, not real data. It is a good first acceptance model for `ubc` (translated to `.ubc` syntax).

## Problems identified before choosing the approach

1. Squiggle-compatible vs Squiggle-like: decided Squiggle-like (ADR 0002).
2. Startup time of an embedded JS engine vs `bc`'s instant start: avoided by ADR 0002.
3. Stateful REPL over a whole-program language: solved by keeping sample sets per variable (ADR 0003) with a fixed seed (ADR 0005).
4. What a distribution prints: ADR 0006.
5. Monte Carlo noise and false precision: 3 significant figures (ADR 0006).
6. Terminal charts portability: braille/blocks always, images optional later.
7. Licences: Guesstimate and Squiggle are MIT; we borrow ideas, not code.

## Naming

See ADR 0007 for the collision checks. Shortlist was `circa`, `napkin`, `ballpark`, `ubc`, `sqc`; the user preferred `ubc` and `napkin`, and chose `ubc` as binary with `uncertain-bc` as project name for discoverability.
